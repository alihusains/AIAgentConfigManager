## Why this task exists

`ProbeCard` (`packages/gui/src/components/ProviderVerify.tsx`, ~line 34) renders
a `<details>` block showing `${probe.curl}\n\n${probe.body ?? probe.error ?? ...}`
as plain text inside a `<pre className="code-block">`. There is no way to copy
that text in one click. `ProvidersView.tsx`'s `ProviderDetailsModal` already has
a working copy-button pattern (a `copy()` function using
`navigator.clipboard.writeText`, a `copied` state that flips an icon between
`Copy`/`Check` from `lucide-react` for ~1.4s, and a toast fallback via
`addToast` when the clipboard API is unavailable) — reuse that exact pattern,
scaled to this component.

## Current state

- `ProbeCard` in `ProviderVerify.tsx` has no clipboard interaction at all.
- `ProviderDetailsModal` in `ProvidersView.tsx` (~lines 653-672) has the
  reference copy-button implementation: `copy(what)` async function,
  `try { await navigator.clipboard.writeText(text); setCopied(what); setTimeout(() => setCopied(null), 1400); } catch { addToast(...) }`,
  with a button showing `<Check size={14} />` while copied and `<Copy size={14} />`
  otherwise.
- Check whether `ProviderVerify.tsx` already has access to `addToast` (via
  `useStore` or a prop) — if not, decide the smallest correct way to surface a
  clipboard-unavailable fallback consistent with the rest of the file (e.g. a
  local inline message) without pulling in unnecessary store coupling if this
  component is meant to stay presentation-only. If genuinely ambiguous, prefer
  the smaller/more local fallback and note the choice in the final report;
  this is not architecture-significant enough to block on.

## Target state

Each `ProbeCard`'s "curl + raw output" block has a small copy button (icon-only,
matching existing `btn-ghost btn-icon btn-sm` sizing used elsewhere in this
codebase) that copies the same text currently rendered in the `<pre>` (the curl
command plus body/error) to the clipboard, with the same copied-state visual
feedback (`Copy` → `Check` for ~1.4s) as `ProviderDetailsModal`.

## Exact requirements

1. Add a copy button beside (or within) each `ProbeCard`'s `<details>`/`<pre>`
   block that copies the exact text currently displayed there
   (`` `${probe.curl}\n\n${probe.body ?? probe.error ?? '(no response body)'}` ``).
2. Use `navigator.clipboard.writeText`, with the same `Copy`/`Check` icon-swap
   feedback pattern (~1.4s) as `ProviderDetailsModal`.
3. Handle the clipboard-unavailable case without throwing — mirror the
   try/catch fallback behavior conceptually (a visible failure indication is
   required; it does not have to be the exact toast call if `addToast` isn't
   already wired into this component — see "Current state" above).
4. Each `ProbeCard` instance manages its own copied/not-copied state
   independently (three `ProbeCard`s render per verification result — copying
   one must not visually affect the others).
